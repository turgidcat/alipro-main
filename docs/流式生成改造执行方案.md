# 流式生成改造执行方案

> 作者：ZCode | 日期：2026-06-20 | 分支建议：`feat/streaming-generation`

---

## 一、改造目标

将章节正文生成从「请求 → 等待 → 一次性返回全文」改为「逐 token 流式输出」，让用户在生成过程中就能看到文字实时涌现，并支持 Esc 键随时中断。同时支持**多章节批量流式生成**——用户选定章节范围后，系统逐章流式输出，每章完成后自动持久化并推进到下一章。

**不改变范围：**
- 只改造 `promptType: 'chapter'`（正文生成），其他 6 种 promptType 保持原样
- 不改变 prompt 构建、审核（audit）逻辑、持久化（persist）流程
- 不改变数据库结构

### 2.2 关键约束

| 约束 | 详情 |
|------|------|
| **audit 需要全文** | `auditGeneratedContent()` 是一次独立的 AI 调用，必须拿到完整正文后才能执行（ai.js:1172） |
| **persist 需要全文** | `upsertGeneratedChapter()` 是 POST 写入 chapters 表，必须拿到完整正文（workbenchApi.js:861） |
| **DeepSeek 兼容 OpenAI** | 支持 `stream: true`，返回 SSE 格式 `data: {"choices":[{"delta":{"content":"..."}}]}` |
| **axios 不原生支持 SSE 消费** | 需要 `responseType: 'stream'` + 手动解析 `data:` 行 |

## 三、技术方案

### 3.1 整体架构（单章模式）

```
前端 ContentWorkspace
  │
  ├── fetch POST /api/generate/stream + ReadableStream reader
  │     │
  │     ├── 逐 chunk: SSE event "delta"  → 追加到 streamingText → 实时渲染
  │     ├── Esc 中断: AbortController.abort() → 关闭连接
  │     │
  │     └── 流结束:
  │           ├── SSE event "done"   → 拿到 usage + 审计结果
  │           ├── SSE event "error"  → 显示错误
  │           └── SSE event "audit" → 审计结果（在 done 之前到达）
  │
  └── 流结束后自动:
        → handlePersistChapterResultCycle()（复用现有逻辑）
```

### 3.1b 整体架构（批量模式）

```
前端 ContentWorkspace
  │
  ├── 用户选择章节范围 [3, 4, 5, 6, 7]
  │
  ├── for each chapterNumber:
  │     ├── SSE event "chapter_start"  → 切换到第 N 章，清空 streamingText
  │     ├── SSE event "delta" × N     → 追加到 streamingText → 实时渲染
  │     ├── SSE event "audit"          → 审计结果
  │     ├── SSE event "done"           → 本章完成
  │     │     → 自动执行 handlePersistChapterResultCycle()
  │     │     → 更新批量进度 [3/5 ✓, 4/5 ✓, 5/5 ⟳]
  │     │     → 自动推进 chapterNumber → 下一章
  │     │
  │     └── Esc 中断 → 当前章停止 → 提示"已生成 X 章，第 Y 章未完成"
  │
  └── 全部完成 / 中断后:
        → 汇总报告（总字数、总耗时、各章审计结论）
```

**核心区别：** 单章模式是一次请求-一串 SSE 事件；批量模式也是**一次请求-一串 SSE 事件**，但事件流中用 `chapter_start` 分隔各章。后端串联执行，不需要前端循环发请求。

### 3.2 SSE 事件协议

#### 单章模式事件

```
data: {"type":"delta","content":"他抬起头，"}

data: {"type":"delta","content":"目光穿过层层迷雾。"}

data: {"type":"usage","input_tokens":1200,"output_tokens":3800}

data: {"type":"audit","verdict":"stable","risks":[],"signals":[...],"airdrop_items":[]}

data: {"type":"done","content_length":2048,"model":"deepseek-chat"}

data: {"type":"error","message":"DeepSeek 服务内部错误"}
```

#### 批量模式事件

```
data: {"type":"batch_start","total":5,"chapters":[3,4,5,6,7]}

data: {"type":"chapter_start","chapter_number":3,"chapter_title":"第三章 暗流涌动"}

data: {"type":"delta","content":"他抬起头，"}
...
data: {"type":"usage","input_tokens":1200,"output_tokens":3800}
data: {"type":"audit","verdict":"stable","risks":[],...}
data: {"type":"chapter_done","chapter_number":3,"content_length":2048,"usage":{...}}

data: {"type":"chapter_start","chapter_number":4,"chapter_title":"第四章 风云突变"}
data: {"type":"delta","content":"夜幕降临，"}
...
data: {"type":"chapter_done","chapter_number":4,"content_length":2100,"usage":{...}}

data: {"type":"batch_done","total_chapters":5,"completed":5,"total_words":10240,"total_time_ms":125000}

data: {"type":"error","chapter_number":5,"message":"DeepSeek 服务内部错误","recoverable":true}
```

**事件顺序保证（单章）：**
1. 零个或多个 `delta`（正文片段）
2. 一个 `usage`（token 用量，DeepSeek 在最后一个 chunk 中给出）
3. 一个 `audit`（审核结果，流结束后才计算）
4. 一个 `done`（标记流正常结束）
5. 如果出错：一个 `error`（替代 done）

**事件顺序保证（批量）：**
1. 一个 `batch_start`（总章数 + 章节号列表）
2. 对于每一章：`chapter_start` → 多个 `delta` → `usage` → `audit` → `chapter_done`
3. 全部完成后：`batch_done`（汇总统计）
4. 某章出错时：`error`（含 `chapter_number` + `recoverable` 标记）。如果 `recoverable: true`，后端会跳过该章继续下一章；如果 `false`，整个批量终止

## 四、分阶段实施

### Phase 1：后端 — DeepSeek 流式调用层

**文件：** `backend/services/deepseek.js`

**改动：** 新增 `generateStream(options)` 方法

```javascript
// 在 DeepSeekService 类中，generate() 方法之后新增
async *generateStream(options) {
  const { prompt, model = 'deepseek-chat', temperature = 0.7, maxTokens = 4000 } = options;

  const payload = {
    model,
    messages: [{ role: 'user', content: prompt }],
    temperature,
    max_tokens: maxTokens,
    stream: true   // ← 关键改动
  };

  const response = await this.client.post('/chat/completions', payload, {
    responseType: 'stream',
    timeout: 300000  // 流式可能更长，5 分钟
  });

  let fullContent = '';
  let usage = null;

  for await (const chunk of response.data) {
    const line = chunk.toString().trim();
    if (!line.startsWith('data: ')) continue;
    const data = line.slice(6);
    if (data === '[DONE]') break;

    try {
      const parsed = JSON.parse(data);
      const delta = parsed.choices?.[0]?.delta?.content;
      if (delta) {
        fullContent += delta;
        yield { type: 'delta', content: delta, fullContent };
      }
      if (parsed.usage) {
        usage = parsed.usage;
      }
    } catch (_) {
      // 跳过无法解析的行
    }
  }

  yield { type: 'usage', usage, fullContent };
}
```

**风险：** axios 的 `responseType: 'stream'` 在 Node.js 中返回的是可读流，需要 `for await...of` 消费。如果 DeepSeek 返回格式异常，`JSON.parse` 会抛错，已被 try-catch 兜住。

**回退：** 如果 `generateStream` 失败，整个流式改造不影响现有 `generate()` 方法。

### Phase 2：后端 — SSE 路由端点（单章 + 批量）

**文件：** `backend/routes/ai.js`

**改动 A：** 新增 `POST /api/generate/stream` 路由 + `handleChapterContentGenerationStream()` 函数

```javascript
// 在 router.post('/generate', ...) 之后新增
router.post('/generate/stream', async (req, res) => {
  const promptType = normalizeText(req.body.promptType || 'chapter');
  if (promptType !== 'chapter') {
    return res.status(400).json({
      success: false,
      error: '流式生成目前仅支持正文生成（promptType: chapter）'
    });
  }

  try {
    // 复用 prepareChapterGenerationContext(req) 公共函数
    // （抽取自 handleChapterContentGeneration L2677-2796）
    const ctx = await prepareChapterGenerationContext(req);

    // ---- SSE 响应头 ----
    res.setHeader('Content-Type', 'text/event-stream');
    res.setHeader('Cache-Control', 'no-cache');
    res.setHeader('Connection', 'keep-alive');
    res.setHeader('X-Accel-Buffering', 'no');

    // ---- 流式生成 ----
    let fullContent = '';
    let usage = null;

    for await (const event of deepseekService.generateStream({ prompt: ctx.prompt, model: ctx.model, temperature: 0.7, maxTokens: ctx.maxTokens })) {
      if (event.type === 'delta') {
        fullContent = event.fullContent;
        res.write(`data: ${JSON.stringify({ type: 'delta', content: event.content })}\n\n`);
      } else if (event.type === 'usage') {
        usage = event.usage;
      }
    }

    // ---- 流结束后执行审计 ----
    const auditResult = await auditGeneratedContent(ctx.auditParams);
    res.write(`data: ${JSON.stringify({ type: 'audit', ...auditResult })}\n\n`);

    // ---- 完成信号 ----
    res.write(`data: ${JSON.stringify({
      type: 'done',
      content: fullContent,
      content_length: fullContent.length,
      usage,
      model: ctx.model
    })}\n\n`);

    res.end();
  } catch (error) {
    try {
      res.write(`data: ${JSON.stringify({ type: 'error', message: error.message })}\n\n`);
      res.end();
    } catch (_) {
      if (!res.headersSent) {
        res.status(500).json({ success: false, error: error.message });
      }
    }
  }
});
```

**改动 B：** 新增 `POST /api/generate/stream/batch` 路由

```javascript
router.post('/generate/stream/batch', async (req, res) => {
  const {
    bookId,
    chapters = [],    // [{ chapterNumber, chapterTitle, ...生成参数 }]
    ...commonParams   // bookTitle, genre, subgenre, platform 等（各章共用）
  } = req.body;

  if (!Array.isArray(chapters) || chapters.length === 0) {
    return res.status(400).json({
      success: false,
      error: 'chapters 参数必须是非空数组'
    });
  }

  const maxBatchSize = 20;  // 安全上限
  const chapterList = chapters.slice(0, maxBatchSize);

  // ---- SSE 响应头 ----
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  res.setHeader('Connection', 'keep-alive');
  res.setHeader('X-Accel-Buffering', 'no');

  const batchStartTime = Date.now();
  const results = [];   // 各章结果记录

  // ---- batch_start ----
  res.write(`data: ${JSON.stringify({
    type: 'batch_start',
    total: chapterList.length,
    chapters: chapterList.map(c => c.chapterNumber)
  })}\n\n`);

  // 检查客户端是否已断开
  let clientDisconnected = false;
  req.on('close', () => { clientDisconnected = true; });

  for (const chapterConfig of chapterList) {
    if (clientDisconnected) break;

    const chNum = chapterConfig.chapterNumber;
    const chTitle = chapterConfig.chapterTitle || '';

    // ---- chapter_start ----
    res.write(`data: ${JSON.stringify({
      type: 'chapter_start',
      chapter_number: chNum,
      chapter_title: chTitle
    })}\n\n`);

    try {
      // 为本章构建上下文（复用公共函数）
      const chapterReq = {
        body: { ...commonParams, ...chapterConfig, bookId, chapterNumber: chNum }
      };
      const ctx = await prepareChapterGenerationContext(chapterReq);

      // 流式生成本章
      let fullContent = '';
      let usage = null;

      for await (const event of deepseekService.generateStream({
        prompt: ctx.prompt,
        model: ctx.model,
        temperature: 0.7,
        maxTokens: ctx.maxTokens
      })) {
        if (clientDisconnected) break;
        if (event.type === 'delta') {
          fullContent = event.fullContent;
          res.write(`data: ${JSON.stringify({ type: 'delta', content: event.content })}\n\n`);
        } else if (event.type === 'usage') {
          usage = event.usage;
        }
      }

      if (clientDisconnected) break;

      // 审计
      const auditResult = await auditGeneratedContent(ctx.auditParams);
      res.write(`data: ${JSON.stringify({ type: 'audit', ...auditResult })}\n\n`);

      // 持久化本章（后端直接写入 DB，不再依赖前端二次调用）
      const persistResult = await persistGeneratedChapter({
        bookId,
        chapterNumber: chNum,
        chapterTitle: chTitle,
        content: fullContent
      });

      // ---- chapter_done ----
      res.write(`data: ${JSON.stringify({
        type: 'chapter_done',
        chapter_number: chNum,
        content_length: fullContent.length,
        usage,
        audit_verdict: auditResult.verdict,
        persisted: !!persistResult.success
      })}\n\n`);

      results.push({
        chapterNumber: chNum,
        success: true,
        contentLength: fullContent.length,
        auditVerdict: auditResult.verdict
      });

    } catch (error) {
      // ---- 本章失败 ----
      res.write(`data: ${JSON.stringify({
        type: 'error',
        chapter_number: chNum,
        message: error.message,
        recoverable: true  // 章节级失败，继续下一章
      })}\n\n`);

      results.push({
        chapterNumber: chNum,
        success: false,
        error: error.message
      });
      // recoverable: true → 跳过这章，继续下一章
    }
  }

  // ---- batch_done ----
  const totalTimeMs = Date.now() - batchStartTime;
  const completedCount = results.filter(r => r.success).length;
  const totalWords = results.reduce((sum, r) => sum + (r.contentLength || 0), 0);

  res.write(`data: ${JSON.stringify({
    type: 'batch_done',
    total_chapters: chapterList.length,
    completed: completedCount,
    failed: chapterList.length - completedCount,
    total_words: totalWords,
    total_time_ms: totalTimeMs,
    results   // 各章摘要，前端可用于生成报告
  })}\n\n`);

  res.end();
});
```

**关键设计决策（批量模式）：**

| 决策 | 理由 |
|------|------|
| **后端串联执行，不是前端循环发请求** | 前端只需要一个 SSE 连接，后端按序逐章生成。避免 N 个并发请求压垮 DeepSeek API |
| **后端直接持久化** | 批量模式下每章完成后后端直接 `upsert` 到 chapters 表。前端不需要（也不能）在流中途发 POST 去持久化，因为下一章已经在流了 |
| **recoverable 标记** | 单章失败不影响整体流程，用户可以看到哪些章成功、哪些失败 |
| **req.on('close')** | 监听客户端断开，如果用户关闭页面或按 Esc，后端立即停止后续章节 |
| **maxBatchSize = 20** | 安全上限，避免超长批量占用服务端资源 |
| **不用并发** | DeepSeek API 有速率限制，串行最安全。如果未来需要加速，可以改为有上限的并发 |

**需要新增的后端函数：**

`persistGeneratedChapter()` — 从 `handlePersistChapterResultCycle` 中提取的纯后端版本：

```javascript
// 后端直接写入 chapters 表（批量模式专用）
async function persistGeneratedChapter({ bookId, chapterNumber, chapterTitle, content }) {
  return db.run(
    `INSERT INTO chapters (book_id, chapter_number, title, content)
     VALUES (?, ?, ?, ?)
     ON CONFLICT(book_id, chapter_number)
     DO UPDATE SET title = excluded.title, content = excluded.content`,

}
```

> 如果后续需要，可以作为 `POST /api/generate/stream/batch` 的可选参数 `{ generateFeedback: true }` 加入

### Phase 3：前端 — 流式 API 消费层

**文件：** `frontend-react/src/workbenchApi.js`

**改动：** 新增 `streamChapterContent(payload, { onDelta, onAudit, onDone, onError, signal })` 函数

```javascript
/**
 * 流式生成章节正文
 * @param {Object} payload — 与 generateChapterContent 相同的参数
 * @param {Object} handlers — 回调函数集合
 * @param {AbortSignal} handlers.signal — 用于中断
 * @param {(text: string) => void} handlers.onDelta — 收到文本片段
 * @param {(audit: Object) => void} handlers.onAudit — 收到审计结果
 * @param {(result: { content, usage, content_length, model }) => void} handlers.onDone — 流结束
 * @param {(error: string) => void} handlers.onError — 出错
 */
export async function streamChapterContent(payload, { onDelta, onAudit, onDone, onError, signal }) {
  const response = await fetch(`${API_BASE}/generate/stream`, {
    method: 'POST',
    headers: createHeaders(),
    body: JSON.stringify(payload),
    signal   // AbortController.signal
  });

  if (!response.ok) {
    const data = await response.json().catch(() => ({}));
    throw new Error(data.error || `HTTP ${response.status}`);
  }

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n');
    buffer = lines.pop(); // 最后一行可能不完整，留着

    for (const line of lines) {
      const trimmed = line.trim();
      if (!trimmed.startsWith('data: ')) continue;
      const jsonStr = trimmed.slice(6);

      let event;
      try {
        event = JSON.parse(jsonStr);
      } catch (_) {
        continue;
      }

      switch (event.type) {
        case 'delta':
          onDelta?.(event.content);
          break;
        case 'audit':
          onAudit?.(event);
          break;
        case 'done':
          onDone?.(event);
          break;
        case 'error':
          onError?.(event.message);
          break;
      }
    }
  }
}
```

**注意：** 使用 `fetch` 而非 `EventSource`，因为 `EventSource` 只支持 GET，而我们需要 POST 传递大量参数。

### Phase 4：前端 — 流式生成 Action

**文件：** `frontend-react/src/lib/generationActions.js`

**改动：** 新增 `generateChapterStreamAction()`，与 `generateChapterAction()` 并列

```javascript
export async function generateChapterStreamAction({
  // ... 与 generateChapterAction 相同的参数
  streamChapterContent,   // ← 新增：流式 API 函数
  abortControllerRef,     // ← 新增：用于存储 AbortController 引用
  setStreamingText,        // ← 新增：设置正在流式输出的文本
}) {
  // 前置校验（与 generateChapterAction 完全相同）
  // ... generationReadiness / generationRiskReview 检查 ...

  const controller = new AbortController();
  abortControllerRef.current = controller;

  setIsGenerating(true);
  setStreamingText('');

  try {
    const payload = { /* ... 与 generateChapterAction 相同的请求体 */ };

    await streamChapterContent(payload, {
      signal: controller.signal,

      onDelta(text) {
        setStreamingText(prev => prev + text);
      },

      onAudit(auditResult) {
        // 暂存审计结果，流结束后使用
        auditResultRef.current = auditResult;
      },

      onDone(result) {
        const content = result.content || streamingTextRef.current || '';
        handlePersistChapterResultCycle({
          content,
          normalizedPlan,
          chapterStructure,
          chapterTitle,
          targetWordCount,
          successTitle: '正文已生成',
          successText: '正文和本章反馈都已写回。',
          openResultModal: true
        });
      },

      onError(message) {
        setGenerationState({
          ...generationState,
          statusKind: 'error',
          statusTitle: '生成失败',
          statusText: message
        });
      }
    });

    return true;
  } catch (error) {
    if (error.name === 'AbortError') {
      // 用户手动中断 — 不报错，保留已生成的文本
      const partialContent = streamingTextRef.current;
      if (partialContent) {
        setGenerationState({
          ...generationState,
          statusKind: 'warning',
          statusTitle: '生成已中断',
          statusText: `已生成 ${partialContent.length} 字。你可以继续编辑，或重新生成。`
        });
        // 可选：把部分文本写入编辑器，让用户决定是否保存
      }
      return false;
    }

    setGenerationState({
      ...generationState,
      statusKind: 'error',
      statusTitle: '生成失败',
      statusText: error.message
    });
    return false;
  } finally {
    setIsGenerating(false);
    abortControllerRef.current = null;
  }
}
```

### Phase 3b：前端 — 批量流式 API 消费层

**文件：** `frontend-react/src/workbenchApi.js`

**改动：** 新增 `streamChapterBatch(payload, { onChapterStart, onDelta, onAudit, onChapterDone, onBatchDone, onError, signal })` 函数

```javascript
/**
 * 批量流式生成多章正文
 * @param {Object} payload
 * @param {string} payload.bookId
 * @param {string} payload.bookTitle
 * @param {string} payload.genre
 * @param {Array}  payload.chapters — [{ chapterNumber, chapterTitle, ...生成参数 }]
 * @param {Object} payload.commonParams — 各章共用参数（genre, platform, wordCount 等）
 * @param {Object} handlers — 回调（比单章多 onChapterStart / onChapterDone / onBatchDone）
 * @param {AbortSignal} handlers.signal
 */
export async function streamChapterBatch(payload, { onChapterStart, onDelta, onAudit, onChapterDone, onBatchDone, onError, signal }) {
  const response = await fetch(`${API_BASE}/generate/stream/batch`, {
    method: 'POST',
    headers: createHeaders(),
    body: JSON.stringify(payload),
    signal
  });

  if (!response.ok) {
    const data = await response.json().catch(() => ({}));
    throw new Error(data.error || `HTTP ${response.status}`);
  }

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let buffer = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    buffer += decoder.decode(value, { stream: true });
    const lines = buffer.split('\n');
    buffer = lines.pop();

    for (const line of lines) {
      const trimmed = line.trim();
      if (!trimmed.startsWith('data: ')) continue;
      const jsonStr = trimmed.slice(6);

      let event;
      try { event = JSON.parse(jsonStr); } catch (_) { continue; }

      switch (event.type) {
        case 'batch_start':
          // 批量开始，可初始化进度条
          break;
        case 'chapter_start':
          onChapterStart?.(event);
          break;
        case 'delta':
          onDelta?.(event.content);
          break;
        case 'audit':
          onAudit?.(event);
          break;
        case 'chapter_done':
          onChapterDone?.(event);
          break;
        case 'batch_done':
          onBatchDone?.(event);
          break;
        case 'error':
          onError?.(event);
          break;
      }
    }
  }
}
```

> 注意：`streamChapterBatch` 内部的事件解析逻辑与 `streamChapterContent` 完全相同。可以抽取一个 `parseSSEStream(reader, handlers)` 公共函数，让两者共用。实际实现时推荐这样做。

### Phase 4b：前端 — 批量流式 Action

**文件：** `frontend-react/src/lib/generationActions.js`

**改动：** 新增 `generateChapterBatchStreamAction()`

```javascript
export async function generateChapterBatchStreamAction({
  selectedBookId,
  chapters,               // [{ chapterNumber, chapterTitle, chapterPlan, ... }]
  planningState,
  setIsGenerating,
  streamChapterBatch,
  abortControllerRef,
  setStreamingText,
  setBatchProgress,       // 新增：批量进度状态 { current, total, completed, failed, chapterTitle }
  setGenerationState,
  onChapterSwitched      // 回调：通知外部切换到第 N 章（刷新编辑器内容）
}) {
  // 前置校验
  if (!chapters?.length) return false;
  if (!selectedBookId) return false;

  const controller = new AbortController();
  abortControllerRef.current = controller;

  setIsGenerating(true);
  setStreamingText('');
  setBatchProgress({ current: 0, total: chapters.length, completed: 0, failed: 0, chapterTitle: '' });

  try {
    const payload = {
      bookId: selectedBookId,
      chapters: chapters.map(ch => ({
        chapterNumber: ch.chapterNumber,
        chapterTitle: ch.chapterTitle,
        genre: planningState.currentBook.genre,
        subgenre: planningState.currentBook.subgenre,
        platform: planningState.currentBook.platform,
        template: planningState.currentBook.template,
        chapterPlan: ch.chapterPlan,
        wordCount: ch.wordCount || 2000,
        promptType: 'chapter'
      }))
    };

    await streamChapterBatch(payload, {
      signal: controller.signal,

      onChapterStart(event) {
        // 切换到新章节，清空流式文本
        setStreamingText('');
        setBatchProgress(prev => ({
          ...prev,
          current: event.chapter_number,
          chapterTitle: event.chapter_title
        }));
        onChapterSwitched?.(event.chapter_number);
      },

      onDelta(text) {
        setStreamingText(prev => prev + text);
      },

      onChapterDone(event) {
        setBatchProgress(prev => ({
          ...prev,
          completed: prev.completed + 1
        }));
        // 本章持久化已在后端完成，前端只需刷新章节列表
      },

      onBatchDone(result) {
        setGenerationState({
          statusKind: 'success',
          statusTitle: '批量生成完成',
          statusText: `共 ${result.total_chapters} 章，成功 ${result.completed} 章，失败 ${result.failed} 章。总字数 ${result.total_words}，耗时 ${Math.round(result.total_time_ms / 1000)} 秒。`
        });
        setStreamingText('');
      },

      onError(event) {
        setBatchProgress(prev => ({
          ...prev,
          failed: prev.failed + 1
        }));
        if (!event.recoverable) {
          setGenerationState({
            statusKind: 'error',
            statusTitle: '批量生成中止',
            statusText: `第 ${event.chapter_number} 章生成失败：${event.message}`
          });
        }
      }
    });

    return true;
  } catch (error) {
    if (error.name === 'AbortError') {
      setGenerationState({
        statusKind: 'warning',
        statusTitle: '批量生成已中断',
        statusText: '已中止。已完成生 成的章节已自动保存。'
      });
    } else {
      setGenerationState({
        statusKind: 'error',
        statusTitle: '批量生成失败',
        statusText: error.message
      });
    }
    return false;
  } finally {
    setIsGenerating(false);
    abortControllerRef.current = null;
  }
}
```

## 六、风险评估与缓解

### 6.1 技术风险

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|----------|
| DeepSeek SSE 格式与 OpenAI 不完全一致 | 流解析失败 | 低 | `try-catch` 兜住每行解析；无法解析的行静默跳过 |
| axios stream 在 Windows/某些 Node 版本行为差异 | 流消费中断 | 中 | 备选方案：用 Node 原生 `https.request` 替代 axios stream |
| Nginx 代理缓冲导致 SSE 延迟 | 用户看到的是一批一批的文字 | 中 | `X-Accel-Buffering: no` 响应头 + Nginx 配置 `proxy_buffering off` |
| 审计（audit）在流结束后才执行，用户等待 | 流结束后多等 5-10 秒 | 确定会发生 | UI 上明确提示"正在审核..."；审计完成后自动进入 persist |
| 用户在审计期间刷新页面 | 正文丢失（还没持久化） | 中 | `sessionStorage` 缓存最新 streamingText 作为草稿恢复 |
| **批量模式下 API 速率限制** | 后端串行请求 DeepSeek，可能触发 429 | 中 | 批量模式每章完成后加 1-2 秒间隔（`await delay(1500)`）；429 时指数退避重试 |
| **批量模式下单章 context 加载失败** | 整个批量卡住 | 低 | catch 住 `loadBookGenerationContext` 的错误，发 `error` 事件后跳到下一章 |
| **批量模式持久化失败** | 前端看到 chapter_done 但实际没存进 DB | 低 | `persistGeneratedChapter` 返回结果写入 `chapter_done.persisted`；前端在汇总报告中提示 |

### 6.2 用户体验风险

| 风险 | 缓解 |
|------|------|
| 中断后部分正文丢了 | 中断时自动提示"已生成 XXX 字"，提供"保存草稿"按钮 |
| 流式输出太快/太慢 | 不做 throttling（DeepSeek 速度已经受限于模型生成速度） |
| 移动端 Esc 键不可用 | 前端添加"停止生成"按钮，与 Esc 等效 |
| **批量模式下用户等太久** | 实时进度条 + 当前章节名 + 已完成/总章数；每章完成后可以在后台继续，用户可离开页面 |
| **批量中断后已完成的章丢了** | 不可能——后端逐章持久化，中断时已完成的章已在 DB 中 |
| **批量模式下选错章节范围** | 开始前弹出确认面板：显示"将生成第 3-7 章，预计总字数 XXXXX，预计耗时 X 分钟"

### 6.3 回退策略

如果流式改造上线后发现严重问题：
1. **代码回退：** 流式路由是独立端点（`/generate/stream`），旧路由（`/generate`）未改动，前端切回 `generateChapterContent()` 即可完全回退
2. **开关控制：** 可在前端加一个 feature flag `ENABLE_STREAMING = true/false`，一行代码切换
3. **渐进式上线：** 先只在开发环境启用，确认稳定后再推生产
