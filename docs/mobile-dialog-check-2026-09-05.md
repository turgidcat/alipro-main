# 安卓弹窗修复验收

## 已修改

- 资料库底部弹窗统一为视口内的固定高度、固定标题和独立可滚动正文；统一关闭与背景锁滚。
- 全书大纲详情包含 main_outline、volume_outline、detailed_outline；分卷详情补充主题、首尾角色状态及备注。
- 新增角色、AI 阵容规划复用相同弹窗，避免两套实现漂移。
- 通用弹窗、书籍编辑表单、头像裁剪内容区增加小屏滚动边界；生成参数、主题设置、提示词管理限制高度。
- 安卓返回键优先关闭可见弹窗；输入法使用 adjustResize。

## 浏览器交互验证

使用真实组件、隔离长文本夹具，不连接生产数据库。入口 frontend-react/dialog-check.html，不在正式构建入口中。

| 检查 | 结果 |
| --- | --- |
| 390 × 700 全书大纲 | 可滑至详细大纲末尾，scrollTop 2099，末段可见 |
| 390 × 700 分卷详情 | 可滑至备注末尾，scrollTop 2285 |
| 390 × 700 章节细纲 | 可滑至最后一行，剩余滚动距离 0 |
| 新增角色 | 保存按钮位于视口内，可取消关闭 |
| AI 阵容规划 | 可滑到底部操作区，可取消关闭 |
| 通用长文弹窗 | 内容可滑到底部；发现并修正底部操作越界，按钮底边 676 < 700 |
| 320 × 480 全书大纲 | 可滑到底部，无横向溢出 |
| 320 × 480 通用弹窗 | 完成按钮底边 441 < 480 |

## 代码检查覆盖

叙事脉络详情复用 MobileBottomSheet；剧情节点复用 modal-panel/modal-body。书籍编辑、头像裁剪、生成参数、主题设置、提示词管理已逐一检查容器结构并补充相应滚动约束。

## 尚未验证

没有连接安卓真机，尚未验证真实触摸、系统返回键、软键盘、特定厂商安装器。上述不能表述为所有子页面真机验收通过。之前用户报告的安装包损坏原因仍未确认。
