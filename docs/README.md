# docs

项目文档目录。

## 当前定位

这里保留仍然服务于当前 Alipro 版本的说明文档，包括生成链路解释、数据库结构说明、剧情线机制说明和用户操作指南。

## 结构说明

- `生成链路原理注释文档.md`：解释当前生成链路的主要数据流。
- `数据库结构设计.md`：记录数据库表和兼容层设计。
- `小说生成操作指南-大白话版.md`：面向普通用户的操作说明。
- `剧情线*.md`：剧情线机制、进度表和分卷闭环相关说明。
- `章节细纲单一最新稿方案.md`：章节细纲展示和兼容口径说明。
- `changelog.json`：项目变更记录数据源。

## 清理规则

临时验收报告、过期施工看板、一次性排查报告和旧页面规划文档不应继续放在这里。
