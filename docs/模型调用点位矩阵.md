## 调用关系

- 细纲：生成 → 节点/密度/角色三项审校 → 最多2轮纠偏及重新审校。
- 正文：初稿（流式/非流式）→ 按条件调整字数/结尾 → 质量审校 → 按条件定点修稿与再次审校。分支和实际执行顺序以每次记录为准。
- 全书大纲/分卷：首次生成 → 按角色一致性或卷数条件纠偏。
- 章节反馈：反馈生成 → 空结果重试或结构修复。可能由客户端另发请求，不伪装成同一个HTTP操作；可按作品/章节关联查阅。
- 所有DeepSeek适配器请求还可能因502/503/504再次发送；每次尝试单独记录并归到同一个逻辑调用。角色适配器还支持阿里云失败降级DeepSeek。

## 边界

prompt-preview、普通资料保存、角色自动分类等未调用模型，不产生虚假的模型记录。TTS仅记录Node到Python的合成输入与完成信息；Python内部网络包/重试、音频二进制不在文本监控范围。独立裁判脚本有点位；其他开发脚本通过已接入适配器的请求同样可捕获，未知新增调用标记未分类而不静默丢弃。
